**Sovereign SEOS** is a secure, self-verifying software supply chain pipeline built on GitHub Actions. It utilizes **Sigstore/Cosign Keyless Signing** to provide cryptographic proof of origin and integrity.

## 🎯 What This System PROVES
This repository implements a strict verification model. Based on the generated artifacts, a verifier can cryptographically confirm:
1.  **Code & Test Integrity**: The `attestation.json` contains the SHA-256 hash of the source code and the self-test results at the exact moment of execution.
2.  **Identity Integrity**: The Sigstore certificate proves that the artifact was generated by *this specific GitHub Actions workflow* (`seos-runner.yml`) running on *this specific repository* and commit.
3.  **Tamper-Evidence**: If any byte of the `attestation.json` is modified post-signing, the `cosign verify-blob` command will fail.

## ⚠️ What This System DOES NOT PROVE (Limitations)
To maintain transparency, it is crucial to state what is *not* guaranteed:
1.  **Vulnerability-Free Code**: This pipeline does not currently perform automated vulnerability scanning (e.g., CVEs). The code passed self-tests, but may still contain security flaws.
2.  **Human Review**: The Branch Protection rules may be bypassed by the repository owner. The cryptographic signature proves the *machine* built it, not that a human reviewed it.
3.  **Runtime Security**: This verifies the artifact at build time. It does not guarantee the environment where the artifact is ultimately deployed.

## 🔍 How to Verify (Trust, but Verify)

You can independently verify the authenticity of the generated artifacts offline using `cosign`. 

1. Download the artifacts (`attestation.json` and `attestation.sigstore.json`) from a recent workflow run.
2. Install [Cosign](https://docs.sigstore.dev/cosign/installation/).
3. Run the following command (replace `<commit-sha>` with the actual commit):

```bash
cosign verify-blob \
  --bundle attestation.sigstore.json \
  --certificate-identity 'https://github.com/yinghiy13-collab/Sovereign-SEOS-/.github/workflows/seos-runner.yml@refs/heads/main' \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com \
  attestation.json
